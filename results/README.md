# results/

Generated artefacts. **Everything here is regenerated by `make run`** (i.e.
`python -m denominator run`) from the committed inputs — do not hand-edit.

| File | What it is | Regenerated by |
|---|---|---|
| `paper_numbers.json` | Every headline figure with its 95% credible interval, keyed for direct quotation in the paper | `make run` |
| `tables.md` | Paper-ready tables (burden grid, prevention, residual, allocation) | `make run` |
| `methods.md` | Long-form methods & provenance narrative (auto-generated from the parameter set) | `make run` |
| `figures/` | Exported figures | `make run` |
| `Genetic_Medicine_Revision_and_Methods.docx` | Editorial revision pass + drop-in Methods/Data-Sources section for the manuscript | `python results/build_revision_docx.py` |
| `build_revision_docx.py` | Builds the `.docx` above from `paper_numbers.json` + the library tiers (needs `python-docx`) | — |

Reproducibility stamp: `app/public/data/meta.json` records the git commit, RNG seed, and
draw count for each run, so any figure can be traced to the exact pipeline state.
