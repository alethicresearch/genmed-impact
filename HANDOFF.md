# Repo handoff — manuscript ↔ analysis

Two agents are working on this project in parallel: one on the **manuscript prose**, one on the
**analysis pipeline and research page**. This file is the contract between them. It exists so
neither has to reconstruct the other's conventions, and so the paper and the page cannot drift
apart without someone noticing.

If you are the manuscript agent, read this before quoting a single number.

---

## 1. Who owns what

Edit freely inside your own column. Before touching the other column, say so in a commit message
or leave a note here — the failure mode is two agents rewriting the same paragraph from different
assumptions, not merge conflicts.

| Manuscript agent owns | Analysis agent owns | Shared — coordinate |
|---|---|---|
| The manuscript document itself | `core/**` (pipeline, constants, library, tests) | `README.md` |
| `results/build_revision_docx.py` (prose of the generated pass) | `app/**` (research page) | `REVIEW_TRACKER.md` |
| Section structure, argument, citations | `results/*.json`, `*.md` (all generated) | `ANALYSIS_LOG.md` |
| | `app/public/data/*.json` (all generated) | This file |

**Branch: `main` only.** An earlier session branch (`claude/session-setup-*`) exists and is stale —
do not develop on it. Pull before you start; push when a unit of work is done rather than holding
a large local diff.

## 3. Generated files — hand-edits will be destroyed

| File | Regenerated by | If you hand-edit it |
|---|---|---|
| `results/paper_numbers.json`, `tables.md`, `methods.md` | `make run` | Silently overwritten |
| `app/public/data/*.json` | `make run` | Silently overwritten |
| `results/Genetic_Medicine_Revision_and_Methods.docx` | `make docx` | **Silently overwritten** |

That last one is the trap. The `.docx` in `results/` is **not the authors' manuscript** — it is a
generated editorial pass (framing fix, drop-in Methods section, updated Table 1) built by
`results/build_revision_docx.py` from `paper_numbers.json`. To change its prose, edit the script,
not the document. The authors' actual manuscript is not in this repo.

## 4. Vocabulary the paper and the page must share

These are not stylistic preferences; each one encodes a distinction the paper exists to draw.

- **Two axes, never one status.** Every condition carries a **prevention** axis
  (`preventable` / `detectable_only` / `not_preventable`, always with *by which tool*) and a
  **treatment intent** axis (`curative` / `disease_modifying` / `palliative` / `none`). Never write
  "preventable or treatable" as a single scale, and never write that a condition has **no
  genetic-medicine option** — that phrasing conflates the existing stack with editing, which is the
  error the project was reframed to fix.
- **Addressable by existing tools** vs **editing-relevant residual**. These are the two halves, and
  they are complements by construction.
- **Editing-only prevention** = S1 = reproductive configurations where no unaffected embryo can be
  selected. Not "cases only editing can treat".
- **Gene addition is not gene editing.** Zolgensma, Lenmeldy and X-SCID therapies add a working
  copy; they do not correct a sequence. Casgevy edits, but disrupts a different gene rather than
  repairing the sickle variant.
- **Prenatal diagnosis prevents no disease.** It reduces affected births in the model only via a
  decision not to continue an affected pregnancy. **Newborn screening prevents no births at all** —
  it enables earlier treatment.
- **Reproductive burden** is a dimension of impact, distinct from the disease outcome.
- The glossary the page uses is `app/src/glossary.ts`. If the paper introduces a term, add it there
  too, or the two drift.

## 5. Claims that need care

Traps that have already caught one of us at least once:

1. **The headline S1 figure excludes congenital deafness** (an ethically contested classification).
   Including it adds ~12,320/yr. State which convention a sentence is using.
2. **Strict and permissive are different scenarios, not a range.** 0.18% vs 1.73% of serious
   disease. The paper must say which it leads with (tracker A5).
3. **S2 strict is too skewed for its median to stand alone** — interval 1–17,854. Quote the
   interval (tracker D9).
4. **Rare-condition figures are orders of magnitude, not estimates.** S1 interval width runs from
   ~6× for the commonest contributing condition to ~11,000× for the rarest (tracker D8).
5. **Funding-market impacts are never summed.** Programmes overlap; the same affected birth can be
   avoided by more than one. The pipeline flags this explicitly and the tests enforce it.
6. **The five normative positions are stipulated, cited positions — not survey results.** No
   elicitation has been run. The outcome ledger is deliberately empty.
7. **Gates 3 and 4 of the editing ladder are unquantified by construction.** The analysis says which
   molecular change would be needed, not how often making it would succeed. Do not let prose imply
   a success rate.
8. **The catalogue is a lower bound**, not an exhaustive census.

## 6. Before the paper can make its claims

`REVIEW_TRACKER.md` is the single list of what is open. Section **A** is the part that blocks the
manuscript — nine decisions only the authors can make, including the attribution stance, the
severity threshold, whether deafness is in or out, whether prenatal diagnosis counts, which
residual leads, and the author list itself. Section **D** is the limitations the write-up must
state explicitly.

When a decision is made, mark it in the tracker and record where it is documented — `ANALYSIS_LOG.md`
for analytic calls, the manuscript for editorial ones.

## 7. Live item: AlphaGenome Atlas (Sept 2026)

The analysis side has already placed this; the manuscript side has not. Material is in the README's
**Intellectual context** section and in the *Which technology?* view of the research page, and the
framing to preserve is:

- Its demonstrated value is **diagnostic** — it belongs to the existing genetic-medicine stack, not
  to editing. A variant nobody can classify cannot be screened for or selected against either.
- It sharpens how gate 1's population is **characterised** and moves **none** of the four gates.
- The authors' own stated limitation — that the model captures cis-regulatory grammar and does not
  model trans-acting mechanisms, which mediate a substantial proportion of complex-trait
  heritability — is a constraint on the future-capacity polygenic scenario worth citing in their
  voice rather than ours (tracker D10).
- The asymmetry itself is the point: interpretation is advancing, correction is not (tracker D11).

## 8. Verify before you push

```bash
make run          # regenerate every figure from committed inputs
make test         # 100 invariant tests, including guards against fabricated data
make app-build    # the research page must still compile
```

The test suite is not decoration — it enforces the project's evidentiary discipline. Several tests
exist specifically to fail if someone hard-codes an efficiency or safety number, renders a raw
provenance note into the UI, sums non-additive impacts, or lets the deterministic diagnostic leak
into reported results. If one of those fails, the fix is the claim, not the test.
